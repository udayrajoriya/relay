A MORE CONNECTED WORKFLOW

Meet your browser companion.

One-click downloads, optional automatic capture, and direct video and audio discovery.

  1. Load the extension

    Open the extension folder below. In Chrome or Edge, open the extensions page, enable Developer mode, and load the chromium folder unpacked. For Firefox, use about:debugging → This Firefox → Load Temporary Add-on and select firefox/manifest.json.

  2. Pair with Relay

    Copy your private pairing token and paste it into the extension popup. Click “Connect”. Keep Relay running while downloading.

  3. Make it yours

    Right-click links to send them to Relay. Enable automatic capture in the popup if desired. Play a video, then open the popup to see detected media.

Direct HTTP(S) files only. DRM, HLS/DASH playlists, blob URLs, and media requiring browser cookies are not supported. Firefox temporary extensions must be reloaded after restarting Firefox.
